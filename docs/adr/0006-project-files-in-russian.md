# Файлы проекта и сообщения коммитов пишутся на русском

2026-10-29 пользователь решил писать файлы проекта на русском; `README.md` уже был на русском. С этого дня по-русски пишутся `CLAUDE.md`, `docs/adr/`, `GLOSSARY.md`, `.claude/skills/` и сообщения коммитов; прошлые коммиты не переписываются. Идентификаторы, команды, пути и имена из API остаются как есть, поэтому слаг нового ADR пишется латиницей, как у прежних. У термина в глоссарии два имени: русское, совпадающее с `README.md`, и английское в скобках. Имя из кода стоит в бэктиках (`band`, `spinnerSuffix`), а у термина без имени в коде остаётся его прежнее английское имя. Навыки harness и mattpocock-skills находят части этих файлов по английским именам, поэтому строки, которые они ищут буквально, остаются как есть: `## Agent skills` с подразделами, `Done =`, а в глоссарии `## Language` и `_Avoid_:`. Заголовок, на который навык ссылается по имени, пишется по-русски с именем из шаблона в скобках: `## Как мы работаем (How we work)`. Файлы, написанные до решения, переводятся одним отдельным коммитом, без изменения смысла и с «только перевод» в сообщении. Решение не касается кода, комментариев в нём, манифестов и `docs/agents/`, который `/setup-matt-pocock-skills` пересоздаёт по-английски.
