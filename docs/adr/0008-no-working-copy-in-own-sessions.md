# Сессии в самом репозитории не загружают рабочую копию

ADR 0007 записал `CLAUDE_CODE_AUTO_MODE_SERVER=0` в общий `.claude/settings.json`, и это было не то место: причина отказа личная, ведь `CLAUDE_CODE_PLUGIN_DIRS` задан в пользовательских настройках мейнтейнера. У любого, кто откроет репозиторий без загруженной рабочей копии, эта переменная перенесла бы классификатор на клиент за его токены без всякой пользы. По существу ADR 0007 взвешивал только застревание против цены. Сервер пропускал не любую запись, а запись в папку мода, загруженного внутрь процесса. loopline вешает хуки на `tool.call` и `turn.step` и запускает процессы через `$.process.run`, а правка попадает в живую сессию в конце хода. Значит, агент меняет код, который со следующего хода работает внутри его собственного процесса: например, одна строка `on("tool.check", …)` в `hooks/register.tsx` одобряла бы вызовы инструментов без классификатора. Такие записи Claude Code намеренно отправляет на проверку. С ADR 0007 их одобрял бы локальный классификатор, хотя он сам пометил перевод ADR 0005 как `[Self-Modification]`.

2026-10-29 решено иначе: сессии в самом репозитории запускаются командой `claude --settings '{"env":{"CLAUDE_CODE_PLUGIN_DIRS":""}}'`, и рабочая копия в них не загружается. Запись в репозиторий тогда становится обычной правкой в рабочей папке, auto mode одобряет её сам, сервер проверяет остальные действия как обычно, и лишних токенов нет. Проверка в живой сессии идёт в `/tmp` и берёт рабочую копию из пользовательских настроек, как и сессии в других проектах; это решение их не задевает. Цена: в сессиях самого репозитория нет полосы loopline, а сессия, запущенная без флага, получает «gave no verdict» на каждую запись и перезапускается с флагом.

Основание — пробные запуски `claude -p` в auto mode в этом репозитории с настоящими пользовательскими настройками:
- без изменений запись отклоняется;
- `CLAUDE_CODE_PLUGIN_DIRS` в `.claude/settings.local.json` не действует: Claude Code пишет, что project-scoped settings can't set this key;
- через `--settings` пустая строка и путь к пустой папке одинаково отключают загрузку, и запись проходит без классификатора;
- `CLAUDE_CODE_AUTO_MODE_SERVER=0` из `.claude/settings.local.json` читается, и запись проверяет локальный классификатор, но этот вариант отвергнут по причине самоизменения, изложенной выше.
