# Уведомление внутри Claude Code — третье место показа, только для того, на что нужно ответить сейчас

До 2026-10-30 `CLAUDE.md` и раздел безопасности README говорили, что мод рисует только полосу и суффикс спиннера. При этом он уже показывал уведомления внутри Claude Code (`$.ui.toast`): о порогах контекста и лимитов и о повторяющемся сбое. Мейнтейнер признал уведомление законным третьим местом показа. Убрали в своё время desktop-уведомления операционной системы, а сообщения внутри Claude Code под это не попадали.

Чтобы уведомления не стали шумом, как desktop-уведомления, у них есть правило:
- уведомление получает только событие, на которое пользователю нужно ответить сейчас и которого не видно в другом месте;
- каждый вид приходит не чаще раза на порог;
- всё остальное показывает полоса.
