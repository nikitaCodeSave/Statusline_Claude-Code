# Новый элемент полосы нужен всем пользователям, не дублирует Claude Code и берёт готовый факт

2026-10-30 мейнтейнер провёл аудит. Он сравнил то, что декларации Claude Code 2.1.312 отдают моду о сессии, с тем, что рисует полоса. Мерило — интенсивная многодневная работа над проектом. Кандидатов оказалось много, приняты три: незапушенные коммиты, отказы в вызовах за ход и признак worktree. Остальные отклонены. Причины отказа теперь стали условиями для любого нового элемента, сверх того, что это состояние сессии из Claude Code или git.

- **Элемент нужен любому пользователю мода.** loopline ставят с GitHub, поэтому элемент под рабочий процесс мейнтейнера не проходит. Так отклонены идущий rebase или merge и конфликты.
- **Элемент не дублирует то, что Claude Code показывает сам.** Под это условие попали упавшие агенты (о них есть уведомление о задаче), ненормальный конец хода (он виден в транскрипте), постоянная часть контекста (её показывает `/context`), режим разрешений в футере и очередь промптов.
- **Элемент берёт готовый факт из `$`, из события или из локального git.** Не годятся:
  - состояние, собранное из результатов вызовов: пробуждения `/loop` из ответов `ScheduleWakeup` и `CronCreate`;
  - эвристика: угаданная базовая ветка для ветки без upstream;
  - разбор транскрипта. Это формат, который Claude Code меняет без предупреждения, поэтому транскрипт читают только там, где факта нет в API, как для счётчика сжатий.
- **Элемент не строится на событиях `classic.*`.** При управляемых настройках и при входе через Team или Enterprise встроенная защита не передаёт их модам. Мейнтейнер работает именно так и не увидит такой элемент, а значит, и не проверит его в живой сессии.
- **Источник — текущая сессия.** Многодневная работа служит мерилом пользы, но не источником данных. Сведения о других сессиях проекта есть только в их транскриптах, поэтому они отклонены (`.out-of-scope/cross-session-elements.md`). Преемственность между сессиями держат локальный git и лимит 7d.
- **Git только локальный, без сети.** Отставание от remote, PR и CI не показываются.
- **Элемент виден, только когда ему есть что сказать.** Нулей и пустых значений в полосе нет.
- **Новому элементу можно занять новую строку полосы,** если в существующих ему нет места.

Условия записаны в «Охвате» `CLAUDE.md`, отклонённые кандидаты с причинами лежат в `.out-of-scope/`.
