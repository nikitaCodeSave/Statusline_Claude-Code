# Когда auto mode отклоняет запись в репозиторий, мейнтейнер переключается на ручной режим

Рабочая копия загружается как мод в каждую сессию мейнтейнера через `CLAUDE_CODE_PLUGIN_DIRS`, и сессии в самом репозитории не исключение. Поэтому в auto mode запись в репозиторий отклоняется с «gave no verdict (it skipped this action)»: Claude Code отправляет на проверку запись в папку мода, загруженного внутрь процесса, а серверная проверка её пропускает. 2026-10-29 пользователь решил не обходить это настройками. Флаг запуска из ADR 0008 он счёл слишком жёсткой привязкой, локальный классификатор из ADR 0007 одобрял бы правки кода, который работает в процессе самого агента, а `CLAUDE_CODE_PLUGIN_DIRS` в `.claude/settings.local.json` Claude Code не принимает. Когда запись отклоняется так, агент не ищет обходных путей: он говорит об этом, а мейнтейнер переключает режим на ручной (Shift+Tab) и одобряет записи сам. Проектные и пользовательские настройки ради этого не меняются.
