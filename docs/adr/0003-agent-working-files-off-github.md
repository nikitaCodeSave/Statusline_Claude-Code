# Рабочие файлы агентов не попадают на GitHub

Корень репозитория — это плагин, поэтому каждый закоммиченный файл попадает в установленные копии пользователей, а пользователи устанавливают мод через `claude plugin`, и им нужны только мод и `README.md`. `.scratch/` (спецификации и тикеты), `docs/agents/` (настройка mattpocock-skills, которую пересоздаёт `/setup-matt-pocock-skills`) и `docs/research/` внесены в `.gitignore` и лежат только на машине мейнтейнера. Руководство и решения для изменения мода (`CLAUDE.md`, `.claude/`, `docs/adr/`, `GLOSSARY.md`) остаются в git ради истории и резервной копии; 2026-10-29 вариант игнорировать весь слой агентов рассмотрели и по этой причине отвергли. Поскольку спецификация или исследовательская заметка не оставляет истории, ADR вписывает в себя то, на что опирается из неё, вместо ссылки на её путь.
