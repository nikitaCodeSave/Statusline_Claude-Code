# В этом проекте auto mode проверяет действия собственным классификатором Claude Code

2026-10-29 пользователь попросил, чтобы Claude работал над проектом в auto mode без лишних подтверждений: команды он всё равно одобряет. Тогда каждая запись файла в репозиторий отклонялась с «The server-side auto mode classifier gave no verdict (it skipped this action)». Причина в том, что рабочая копия загружена в каждую сессию как мод через `CLAUDE_CODE_PLUGIN_DIRS`. Claude Code 2.1.312 не одобряет запись в папку загруженного мода сам и отправляет её на проверку, даже когда её разрешает правило `Edit(...)`; серверная проверка такую запись пропускает, и Claude Code её отклоняет. Это показали пробные запуски `claude -p` в auto mode: в копии репозитория, загруженной через `CLAUDE_CODE_PLUGIN_DIRS`, запись отклоняется, в той же копии без загрузки проходит без проверки, а с `CLAUDE_CODE_AUTO_MODE_SERVER=0` её проверяет собственный классификатор Claude Code и разрешает. `CLAUDE_CODE_AUTO_MODE_CLASSIFY_EDITS=0` не помогает: с ним запись отклоняется так же. Поэтому `.claude/settings.json` задаёт в `env` `CLAUDE_CODE_AUTO_MODE_SERVER=0`, и Claude Code учитывает её из проектных настроек. Цена: в сессиях этого проекта каждая проверка идёт отдельным запросом (в пробном запуске около 2,5 с) и засчитывается в использование токенов; в остальных проектах проверку по-прежнему бесплатно делает сервер. Собственный классификатор при этом судит по содержанию: он отклонял перевод ADR 0005 как `[Self-Modification]` и этот ADR как `[Instruction Poisoning]`, и такие записи делаются в обычном режиме разрешений с одобрением пользователя. Правила `Edit(...)` из ADR 0005 в auto mode эту запись не пропускали; они остаются для других режимов. Перестать загружать рабочую копию в каждую сессию тоже убирает отказ, но тогда правка доходит до живой сессии только после обновления установленной копии, и пользователь выбрал проектную настройку. Документация называет `CLAUDE_CODE_AUTO_MODE_SERVER` временной настройкой: если новый релиз её уберёт и запись снова начнёт отклоняться, это решение пересматривается.
