# Счётчик отказов в вызовах за ход

Отклонено 2026-10-30, после живой пробы на Claude Code 2.1.312.

**Предлагалось:** `⊘ N denied · <последний вызов>` в третьей строке полосы. Это число вызовов за ход, в которых отказали правило `deny`, хук PreToolUse или классификатор auto mode, без вашего собственного «No» в диалоге.

**Почему нет:** готовым фактом до мода доходят только отказы правилом и хуком. Отказ классификатора, «No» в диалоге и отказ в режиме `dontAsk` отличаются от обычной ошибки инструмента только текстом, который Claude Code пишет для модели. Распознавать этот текст запрещает ADR 0010. Без классификатора элементу не остаётся тихих отказов в auto mode, ради которых его и предлагали. А повтор одного и того же отказа и так ловит `⚠ … failed N× in a row`, потому что отказ приходит как ошибка.

Что мод видел в пробе (мод-зонд в `/tmp`, сессия в tmux):

| Отказ | `tool.check` | `next(e)` в `tool.call` |
|---|---|---|
| правило `deny` | `decision: "deny"`, `rule` | `isError: true`, текст «Permission to use … has been denied.» |
| хук PreToolUse (exit 2) | `decision: "deny"`, `hook: "PreToolUse"` | `isError: true`, текст ошибки хука |
| классификатор auto mode | `decision: "ask"`, решение классификатора сюда не попадает | `isError: true`, текст «… denied by the Claude Code auto mode classifier …» |
| «No» в диалоге | `decision: "ask"` | `isError: true`, текст «The user doesn't want to proceed …» |

Поле `deny` в результате `tool.call` не появлялось ни разу. Отказ в вызове субагента приходит с его `agentId` в обоих событиях.

Сейчас решение классификатора готовым фактом есть только в `classic.PermissionDenied`, а события `classic.*` ADR 0010 исключает. Если Claude Code начнёт отдавать его другим событием или полем, отказ стоит пересмотреть.
