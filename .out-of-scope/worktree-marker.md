# Признак worktree

Отклонено 2026-10-30, после живой проверки на Claude Code 2.1.312 и git 2.43.

**Предлагалось:** тусклый знак `⎇` перед веткой в первой строке полосы, только когда сессия идёт в связанном worktree, а не в основной копии. Распознать такой worktree можно одним `git rev-parse --path-format=absolute --git-dir --git-common-dir`: в связанном worktree пути различаются, в основной копии и её подпапках совпадают.

**Почему нет:** признак не меняет следующего действия, а это первое условие «Охвата» в `CLAUDE.md` и ADR 0010.

- Ветку полоса уже показывает. Git не даёт выписать одну ветку в два worktree сразу, поэтому ветка и так однозначно указывает копию.
- Worktree, созданный самим Claude Code (`claude -w <name>`), получает ветку `worktree-<name>`, так что признак повторил бы имя ветки.
- Путь worktree Claude Code показывает в шапке при старте. Свой worktree он убирает сам при выходе из сессии («Worktree removed (no changes)»).

К знанию «это не основная копия» признак ничего не добавляет.
