# Идущая git-операция и конфликты

Отклонено 2026-10-30 при аудите полосы.

**Предлагалось:** `rebasing` / `merging` / `✕ N conflicts` в первой строке полосы вместо diff, пока в рабочей копии идёт rebase или merge либо есть неразрешённые конфликты.

**Почему нет:** элемент рассчитан на рабочий процесс мейнтейнера, а полосу ставят все пользователи с GitHub. В «Охвате» `CLAUDE.md` это условие «нужен любому пользователю мода».
