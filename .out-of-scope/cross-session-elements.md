# Элементы о других сессиях проекта

Отклонено 2026-10-30 при аудите полосы.

**Предлагалось:** показывать сведения о других сессиях того же проекта: сколько их было за день или неделю, сколько они стоили, чем кончилась прошлая, сколько коммитов сделано за день.

**Почему нет:** loopline показывает состояние текущей сессии. Почти всё перечисленное читается только из чужих транскриптов в `~/.claude/projects/<проект>`, а транскрипт — внутренний формат Claude Code, чтение которого пользователь решил свести к минимуму. Многодневная работа служит мерилом пользы элемента, но не источником данных: преемственность между сессиями держат локальный git текущей рабочей копии и лимит 7d, который полоса уже показывает.
