# Сигналы, которые дублируют Claude Code или собираются по косвенным данным

Отклонено 2026-10-30 при аудите полосы.

Каждый из этих элементов нарушает условие «Охвата» в `CLAUDE.md`: он либо показывает то, что Claude Code показывает сам, либо собирает состояние из результатов вызовов и эвристик вместо готового факта.

| Предлагалось | Почему нет |
|---|---|
| `⧉ 2 agents · 1 failed`: упавшие и убитые фоновые агенты | Claude Code сам пишет уведомление о задаче; записи пропадают из `$.agent.list()` через секунды после конца, поэтому статус пришлось бы запоминать |
| `✕ cut at max_tokens` / `✕ API error` / `✕ refused`: ход кончился ненормально | Claude Code показывает это в транскрипте |
| `⏰ 12m`: следующее пробуждение `/loop` или cron | состояние собиралось бы из результатов `ScheduleWakeup`, `CronCreate` и `CronDelete` и устаревало бы |
| `$6.46 +0.84`: стоимость последнего хода | вычисление поверх стоимости, которое не меняет действий |
| `floor 38k`: постоянная часть контекста (системный промпт, схемы MCP, memory, skills) | то же показывает `/context`, а меняется она редко |
| `4 commits`: коммиты этой сессии | нужно запоминать HEAD на старте сессии; действий не меняет |
